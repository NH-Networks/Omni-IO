    Quick Help & Pairing

    Pairing a screen (1W)
    1. Devices → (+): Create a new screen.
    2. Edit: Open that screen's settings.
    3. Physical remote: Hold PROG until screen jogs.
    4. Pair: Click "Pair" in the web UI. The screen jogs again.
    Linking a remote
    1. Press any button on the physical remote; see Last Address above.
    2. Remotes → (+): Add remote (ID is auto-filled).
    3. Edit: Link the desired screen to this remote.
